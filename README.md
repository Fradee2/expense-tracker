# 💰 Expense Tracker

Приложение для отслеживания личных расходов.

## Функционал
- Добавление трат с названием, суммой и категорией
- Удаление записей
- Фильтрация по категориям
- Подсчёт общей суммы расходов
- Сохранение данных в localStorage

## Технологии
- HTML5
- CSS3
- JavaScript (ES6+)
